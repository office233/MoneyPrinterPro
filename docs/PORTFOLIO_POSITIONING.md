# Portfolio positioning

MoneyPrinterPro should be presented as an AI media pipeline and product engineering project.

## What this repository demonstrates

- Full-stack AI product implementation with Next.js, API routes, local storage, and SQLite.
- Image and video generation workflow using external AI providers.
- Persona-oriented prompt orchestration and content planning.
- Optional video scoring service with Python, FastAPI, OpenCV, and face analysis fallback.
- Practical product features such as settings, job history, generated asset serving, and batch generation.

## Best-fit roles

This project is strongest for roles involving:

- applied AI product engineering;
- AI media tooling;
- full-stack product prototyping;
- workflow automation;
- AI-assisted creator tools.

## Interview framing

Use this framing:

> I built an AI media generation pipeline with persona setup, prompt orchestration, image generation, video generation, job tracking, and optional quality scoring. The strongest signal is product integration: connecting model APIs, storage, UI, planning, and evaluation into a working local app.

## Naming note

For professional portfolio use, consider a calmer name such as `ai-content-studio` or `persona-media-pipeline`.
